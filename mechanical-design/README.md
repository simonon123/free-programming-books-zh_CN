# 机械工程设计基础资源

精选免费/开源教材、课程与工具（适用于考试与工程实践）：

核心教材与课程

- MIT OpenCourseWare — Mechanical Engineering（英文）
  - 链接：https://ocw.mit.edu/courses/find-by-topic/#cat=engineering&subcat=mechanicalengineering
- OpenStax — University Physics（力学部分，CC BY，可下载PDF）
  - 链接：https://openstax.org/details/books/university-physics-volume-1
- Autodesk Design Academy（CAD/Fusion 360/AutoCAD 入门，项目式课程）
  - 链接：https://academy.autodesk.com/

开源工具

- LibreCAD（开源 2D CAD，适合工程制图练习）
  - 链接：https://librecad.org/  https://github.com/LibreCAD/LibreCAD

练习建议：结合 OpenStax 的力学基础与 LibreCAD 的制图练习，完成基本受力计算与工程图绘制，配合 Autodesk 官方入门项目练习三维建模与装配。
